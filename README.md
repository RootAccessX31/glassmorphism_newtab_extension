## Installation & Setup
1) Download the ZIP: Click the green Code button near the top right of the repository file list, then select Download ZIP.
2) Extract the files: Locate the downloaded ZIP file on your computer and extract (unzip) its contents into a new, dedicated folder.
3) Open Chrome Extensions: Open Google Chrome and navigate to chrome://extensions/.
4) Enable Developer Mode: Turn on the Developer mode toggle switch located in the top right corner of the page.
5) Load the Extension: Click the Load unpacked button in the top left corner.
6) Select the Folder: Choose the extracted folder containing your extension files.
